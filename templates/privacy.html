What this demo processes

When you upload a ZIP, the application reads supported text files in memory to analyze Python imports. It does not execute uploaded code. Analysis sessions are held in server memory and may be cleared when the server restarts or when the session cache is trimmed.

Storage and sharing

This starter project does not intentionally save uploaded project files to permanent storage, use analytics, or send source code to an AI service. If you deploy or modify it, review hosting logs, infrastructure settings, and any added services before accepting real user code.
